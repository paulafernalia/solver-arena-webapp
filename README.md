# Solver Arena Web App

A responsive web dashboard built with [Plotly Dash](https://dash.plotly.com/) to interact with [Solver Arena](https://github.com/pataq21/SolverArena). 

---

## Dependencies

This project uses [**uv**](https://github.com/astral-sh/uv) for dependency and environment management.

The list of dependencies can be found in `pyproject.toml`. Requires Python 3.13+.

---

## Usage

1. **Clone the repository**
    ```bash
    git clone https://github.com/paulafernalia/solver-arena-webapp
    cd solver-arena-webapp
    ```

2. **Install dependencies**
    ```bash
    uv venv
    uv sync
    ``` 

3. **Run in development mode**
    ```bash
    uv run app.py
    ```
